# Haveli Restaurant — website proposal

A custom five-page restaurant concept, supplied as plain HTML, CSS and JavaScript for manual upload. No build, package installation or account connection is required.

## Preview

Open `index.html` in a browser. For the best experience, use a local static server or your website host. Typography loads from Google Fonts; system fonts are used if offline.

## Upload

Extract the ZIP and upload its contents, including the `assets` folder. Keep `index.html` at the website root, alongside the other HTML files, `styles.css`, and `script.js`. All internal links are relative, so the site can run under a GitHub Pages repository path.

## Pages

- Home: rooftop introduction and signature dishes
- Menu: filterable selection of dishes provided in the brief
- The Rooftop: dining experience and setting
- Celebrations: birthday, family and corporate enquiries
- Visit Us: location, call button and WhatsApp enquiry composer

The enquiry composer opens WhatsApp with the guest's details. The guest must send the message themselves. It does not make or confirm a booking, send an email, or store guest information on a server.

## Details to confirm before a business launch

1. Restaurant-approved logo and photography usage.
2. Current full menu, descriptions, prices and tax information.
3. Daily opening hours and breakfast availability. Public listing and official contact-page hours conflict; exact hours have intentionally been omitted.
4. Reservations and WhatsApp number: the proposal uses +92 300 8414899, as provided and confirmed by the client. The official contact page also lists +92 321 4651051 for reservations.
5. Event packages, capacity, advance notice and booking policy.
6. Final domain and social accounts.

This is an independent presentation concept. The footer identifies it as such and each page has a noindex directive. For an approved official launch, replace that footer notice, update metadata, remove noindex, and add the final domain's canonical and structured data as appropriate.

No live rating, invented review, fixed opening hours, unconfirmed prices or automatic booking confirmation has been added.
